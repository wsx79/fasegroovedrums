# Roadmap

*🇮🇹 [Versione italiana](ROADMAP.it.md)*

Ideas for the next versions of **Fase Groove Drums**, step by step. When one ships, it moves to
the [CHANGELOG](CHANGELOG.md).

- More grooves per genre, refined by ear.
- VELOCITY page (per-step velocity faders) and A/B/C/D parts, as in Fase Groove Piano.
- Undo / redo, your own presets and saved grooves.
- Song window (bars, variation and fill per section), one `.mid` per section.
- Interface in 6 languages, like Fase Groove Piano.
- Windows installer, automatic updates.
- Sync with Fase Groove Piano (same style, same song sections).
